# Remove-SSHKey

Удаляет ключ хоста из `known_hosts` через `ssh-keygen -R`. Хост можно указать по имени или по номеру строки в файле.

Пригодится, когда после переустановки сервера `ssh` пишет `REMOTE HOST IDENTIFICATION HAS CHANGED` и показывает номер строки с устаревшим ключом.

## Требования

- `ssh-keygen` (OpenSSH для Windows входит в Windows 10/11 и Windows Server 2019+).

## Примеры

```powershell
# По имени хоста или IP: то же, что ssh-keygen -R 10.196.16.42
Remove-SSHKey 10.196.16.42
Remove-SSHKey '[git.example.com]:2222'

# По номеру строки: берёт имя хоста из строки 197 и удаляет все его записи
Remove-SSHKey 197

# Другой файл known_hosts
Remove-SSHKey 15 -KnownHosts C:\Temp\known_hosts
```

## Параметры

| Параметр | Описание |
|---|---|
| `HostName` (позиция 0) | Имя хоста, IP, `[host]:port` или номер строки в `known_hosts` |
| `KnownHosts` | Путь к файлу. По умолчанию `$HOME\.ssh\known_hosts` |

## Как работает

- Аргумент только из цифр считается **номером строки**, всё остальное — именем хоста. IP-адрес (`10.1.1.1`) номером не считается.
- Если в строке несколько имён через запятую (`host,10.0.0.1`), удаляется каждое.
- `ssh-keygen` удаляет **все** записи хоста (RSA, ECDSA, ED25519), а не только указанную строку. Прежний файл он сохраняет как `known_hosts.old`.
- Функция откажется работать по номеру строки, если:
  - строки с таким номером нет;
  - в строке нет имени хоста (битая строка, только ключ);
  - имя хоста захешировано (`|1|...`, `HashKnownHosts yes`) — по нему не узнать исходное имя.

> Если `ssh-keygen` пишет `is not a valid known_hosts file`, в файле есть битая строка (номер указан в сообщении). Пока её нет, удаление не работает ни по имени, ни по номеру.
